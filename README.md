# 资料库内容维护说明（library.json）

**一句话**：页面上所有资料条目都存在 `library.json` 里。改这个文件、提交，访客刷新页面就生效——不用重新发布，站点链接永远不变。

- 线上站点：https://ai-ecom-library.app.workbuddy.host/?sharecode=6OF4QAJMAK
- 数据仓库：`Joe-xuliqun/ai-library-data`（**必须是公开仓库**，私有仓库页面读不到）
- 生效延迟：改完 1–5 分钟（CDN 镜像缓存），最长不超过 5 分钟

---

## 一、最常用的三个操作

全程在浏览器里点，不需要装任何工具，手机也能改。

### 1. 换一条的链接 / 标题

1. 打开仓库，点 `library.json`
2. 右上角铅笔图标（Edit this file）
3. 找到那一条，改 `"url"` 或 `"title"` 引号**里面**的内容
4. 页面往下拉，点绿色 `Commit changes`

### 2. 加一条

复制相邻那一条的整个 `{ ... }` 块，粘贴在后面（或前面），改三个地方：`title`、`url`、`code`。

**排序就是编号**：插在哪个位置，页面上就排第几，序号会自动重排，不用手改。

### 3. 删一条

删掉它整个 `{ ... }` 块，**连前面或后面那个逗号一起处理干净**——
数组里最后一个元素后面不允许有逗号。

```json
"items": [
  { "title": "A", "url": "https://a" },      ← 中间留着逗号
  { "title": "B", "url": "https://b" }       ← 最后一条不能有逗号
]
```

## 二、文件结构

```json
{
 "version": "2026-11-19",
 "sections": {
   "articles": {
     "tag": "61 篇",
     "groups": [
       {
         "head": "尹晨公众号AI+电商干货文章集锦",
         "type": "list",
         "count": "21 篇",
         "items": [
           { "title": "字节，绝不能一家独大", "url": "https://mp.weixin.qq.com/s?...", "tag": "尹晨 · 公众号", "date": "11.08", "isNew": true }
         ]
       }
     ]
   }
 }
}
```

三层：`sections`（章节）→ `groups`（分组）→ `items`（条目）。日常只动 `items`。

## 五、条目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 列表里显示的文字。建议 ≤ 46 字，超了手机端会折行 |
| `url` | 是 | 完整网址，`https://` 开头。星球那章可以是站内相对路径 `planet/p123456.html` |
| `code` | 否 | 网盘提取码，一般 4 位。填了会出现「提取码 xxxx」按钮，点一下自动复制 |
| `tag` | 否 | 搜索标签。搜「公众号」「飞书」能命中，不影响显示 |
| `src` | 否 | 列表右侧显示的来源文字（如 `百度网盘`、`飞书文档`）。模板有位置时才显示 |
| `date` | 否 | 列表右侧的日期，格式 `11.08`（月.日） |
| `isNew` | 否 | 写 `true` 才显示蓝色「新」标记，不写就不显示。**不加引号** |

### 关于 `date` 和 `isNew` 的一个注意事项

页面在数据更新时是**整组重绘**的：你改了组里任何一条，这一组的所有行都会按数据重新生成。

所以日期和「新」标记也必须写在数据里——某条没写 `date`，它就不会显示日期。想让某条不显示日期是正常的、想让它显示就把 `date` 写上。

## 七、改完怎么验（三步，两分钟）

### 第 1 步：语法检查（可选但强烈建议）

仓库里附了校验脚本 `check_library.py`，只依赖 Python 标准库（电脑上装了 Python 3 就能跑，不需要 `pip install` 任何东西）：

```bash
python check_library.py
```

会输出每个章节的条目数，以及三类问题：

- ✗ **错误**：条目会显示不出来（缺 url、分组名对不上、章节名拼错、JSON 语法错）
- ! **提醒**：不影响显示（标题太长、提取码位数可疑、字段拼错、链接重复）
- 退出码 0 = 通过，1 = 有错误

### 第 2 步：看镜像地址

浏览器打开（把时间戳换掉强制刷新）：

```
https://cdn.jsdmirror.com/gh/Joe-xuliqun/ai-library-data@main/library.json
```

能看到你刚改的内容就成了，然后等 1–5 分钟再刷新页面。

### 第 3 步：看线上页面

打开站点，硬刷新 `Ctrl + Shift + R`（Mac 是 `Cmd + Shift + R`）。

想确认数据到底加载了没有：按 `F12` 打开控制台，应该能看到一行

```
[资料库] 远程数据已载入：更新 N 个分组，版本 2026-11-19
```

如果看到的是 `[资料库] 未取到远程数据，沿用页面内置内容`，说明数据没取到（网络或仓库问题），页面显示的是发布时的旧数据。

## 八、常见错误对照

| 现象 | 原因 |
|---|---|
| 页面完全没变化 | ① 还没到 5 分钟；② 浏览器缓存没硬刷；③ 改的不是 `main` 分支 |
| 某一组整组不显示新内容 | `head` 和页面上的分组名不一致，或整组从 JSON 里删掉了（删组不会让页面上的组消失，只会保留旧内容） |
| 某个条目消失 / 出现空白行 | 缺 `title` 或 `url`，或该条 `{}` 语法坏了连带整组解析失败 |
| 所有条目突然都没日期了 | 数据里没有 `date` 字段。整组重绘后，没写日期的行就不显示日期 |
| 提取码按钮不见了 | 该条没有 `code` 字段，或 `code` 写成了数字（要加引号：`"code": "a4x6"`） |
| 页面显示旧内容但控制台没报错 | JSON 语法错，回落到发布时内置的数据。用 `check_library.py` 定位 |
| 点链接 404 | 星球长文的相对路径 `planet/xxx.html` 写错了文件名，或该长文页没发布过 |

JSON 语法错误最常见的四个原因：

1. 最后一条后面多了个逗号
2. 用了中文引号 `“ ”` 而不是英文 `" "`
3. 少了一个 `}` 或 `]`
4. 网址里的 `&amp;`（从网页复制来的）没改回 `&`

## 九、绝对不能改的

1. **`sections` 下的 5 个键名**（`articles` / `records` / `planet` / `live` / `docs`）
2. **文件名** `library.json`，且必须在仓库根目录，不能放进子文件夹
3. **仓库名** `ai-library-data` 和账号 `Joe-xuliqun`——页面代码里写死了这两个值
4. **仓库可见性**：必须是 Public。改成 Private，页面立刻读不到数据
5. **分组名**（见第四节表格），包括那个 `Seendance` 的拼写和 `__grid__` 占位名

改这些不是"页面暂时不对"，而是直接失效。
